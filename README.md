# Эволюция · Ретриты с Мастером в 2027 году

Один сайт для всех встреч года: два ретрита в Чиралы и интенсивы в Ясном Поле и Стамбуле. Оформлен в стиле Пространства Эволюции (evolution.place): Roboto, фиолетовые кнопки-«таблетки», светлый сиреневый и мятный фон, крупные фото мест.

- **Главная.** Сразу под заголовком «Эволюция. Ретриты с Мастером в 2027 году» — четыре крупные карточки с фото. Вся карточка — ссылка на страницу встречи. Фото плавно «перелетает» в шапку страницы встречи: так работает в Chrome и Safari 18.2+, в остальных браузерах страница просто открывается.
- **Дальше на главной:** «Ретрит или интенсив?», «Как проходит практика» (карточки ретрита и интенсива с переключателем), как записаться, вопросы, анкета.
- **Страница каждой встречи** — своя ссылка со своим фото и датами в превью Telegram и WhatsApp.
- **Блок для вставки** на другой сайт, например на Тильду. Встречи там обновляются сами (раздел «Как поставить встречи на свой сайт»).
- **Календарь** — «Добавить все встречи в календарь» (`/calendar.ics`), у каждой встречи — Google и Apple/Outlook.

Сайт собирает GitHub Pages, ничего устанавливать не нужно. После правки сайт обновляется примерно через минуту.

## Как добавить или поменять встречу

Каждая встреча — отдельный файл в папке **`_events`**:

| Файл | Встреча |
|---|---|
| `istanbul-january-2027.md` | Интенсив в Стамбуле, 29–31 января 2027 |
| `cirali-spring-2027.md` | Ретрит в Чиралы, 6–14 марта 2027 |
| `istanbul-august-2027.md` | Интенсив в Стамбуле, 6–8 августа 2027 |
| `yasno-pole-2027.md` | Интенсив в Ясном Поле, 10–12 сентября 2027 |
| `cirali-autumn-2027.md` | Ретрит в Чиралы, 31 октября – 8 ноября 2027 |

Даты Стамбула взяты из календаря платформы Мастера.

**Поменять даты, цену или статус:**

1. На GitHub откройте файл встречи и нажмите карандаш (Edit).
2. Поменяйте нужное поле. Подсказки по каждому полю есть в файле `cirali-spring-2027.md`.
3. Нажмите «Commit changes».

**Добавить новую встречу:**

1. Откройте любую встречу → «…» → «Copy» или создайте новый файл в `_events`.
2. Имя файла станет адресом страницы: `alanya-2027.md` → `сайт/alanya-2027/`.
3. Поменяйте название, даты, цену, фото и тексты.

Встреча сама появится на главной в порядке дат, в календаре, в анкете и в блоке для вставки.

**Главные поля:**

- `start`, `end` — даты в формате `2027-03-06`. Если поля пустые, на сайте написано «Даты уточняются».
- `status` — запись:
  - `open` — открыта;
  - `few` — осталось мало мест (число мест — в `seats_left`);
  - `full` — мест нет;
  - `soon` — даты скоро. Вместо заявки кнопка «Узнать даты», люди попадают в лист ожидания.
- `price` — цена. Если поле пустое, на сайте написано «Стоимость уточняется».
- `prices` — ранние цены (необязательно): до какой даты оплаты — какая цена. Сайт сам подсвечивает текущую ступень и пишет «ещё N дней».
- `online: true` — можно участвовать онлайн. Тогда в анкете появляется вопрос «Очно или онлайн». Если человек отметил ещё и встречу без онлайна (интенсив), анкета подсказывает, что онлайн относится только к ретритам в Чиралы.
- `schedule` — расписание. `schedule_title` — свой заголовок блока (без него — «Как устроен день»), `schedule_note` — примечание под расписанием.
- У интенсивов (`kind: intensive`) на странице рядом с датами сайт сам пишет дни недели: «пятница — воскресенье». Они считаются по датам.
- `photo`, `gallery` — фото. Файлы лежат в `assets/img/`.

Когда дата окончания проходит, сайт сам пишет «Встреча прошла», ставит её в конец и убирает из анкеты.

## Общие тексты, контакты, анкета

Всё общее хранится в **`_data/site.yml`**:
- первый экран;
- «Ретрит или интенсив»;
- «Как проходит практика»;
- шаги записи;
- вопросы;
- контакты;
- анкета;
- блок «Другие встречи с Мастером».

**Как проходит практика (`day`).** Две карточки с переключателем: ретрит и интенсив. У каждой — `tab` (подпись на кнопке), `title` и `text` (заголовок и вступление), `rows` (строки расписания: `time`, `what`, `note`). `online: true` показывает под расписанием блок «Онлайн-формат». Если скрипты в браузере отключены, обе карточки просто идут одна за другой.

**Вопросы (`faq`).** Обычный вопрос — это `q` (вопрос) и `a` (ответ), он одинаковый везде. Если для ретрита и интенсива ответы разные, у вопроса есть части `retreat` и `intensive`. На странице ретрита показывается ответ для ретрита, на странице интенсива — для интенсива, на главной — оба ответа под общим вопросом.

Правила записи:
- `*слово*` в заголовке — выделение фиолетовым;
- пустое значение `""` — строки нет;
- неразрывные пробелы после коротких слов сайт ставит сам.

**Платформа Мастера.** Когда она откроется, впишите её адрес в `master_platform_url`. Тогда в блоке «Другие встречи с Мастером» появится кнопка. Можно и наоборот: в календаре платформы поставить ссылки на страницы встреч этого сайта.

## Как поставить встречи на свой сайт (Тильда)

На Тильде: «Все блоки» → «Другое» → **T123 «HTML-код»**. Вставьте в блок:

```html
<iframe id="evo-master-2027" src="https://АДРЕС-САЙТА/embed/" title="Ретриты с Мастером" loading="lazy"
  style="display:block;width:100%;min-height:640px;border:0"></iframe>
<script>
  window.addEventListener('message', function (e) {
    if (e.data && e.data.evoEmbedHeight) document.getElementById('evo-master-2027').style.height = e.data.evoEmbedHeight + 'px';
  });
</script>
```

- Высота блока подстраивается сама. Встречи обновляются сами при каждой правке файлов.
- **Только некоторые встречи:** `…/embed/?show=cirali-spring-2027,cirali-autumn-2027`.
- **Без заголовка:** `…/embed/?title=0`. Параметры можно совместить: `?show=…&title=0`.
- Кнопки в блоке открывают страницу встречи и анкету в новой вкладке.

## Анкета и заявки

- **Сейчас анкета — черновик:** поле `form.endpoint` пустое. Человек заполняет анкету и вместо отправки видит контакты организатора и готовый текст заявки для Telegram или письма.
- **Чтобы заявки приходили сами,** поставьте приёмник по `apps-script/README.md` (15 минут) и впишите его адрес в `form.endpoint`. Тогда:
  - **каждая заявка сразу приходит в Telegram Наталье (@nebazhenova) и Изольде (@izoldaumarova)**: кто, на какую встречу, как связаться, сколько всего заявок на эту встречу и с какой стороны люди (Эволюция, ученики Мастера, новые);
  - **итоги по всем встречам** приходят каждый вечер, если были заявки, и по понедельникам. В любой момент их можно получить, написав боту «итоги»;
  - каждая заявка попадает строкой в Google-таблицу и приходит письмом;
  - **таблицу можно получить файлом Excel**: написать боту «таблица». По понедельникам файл приходит сам — в Telegram и на почту;
  - «Спасибо» человек видит, только когда заявка действительно сохранена;
  - если пропал интернет, ответы остаются на странице, а сайт предлагает отправить ещё раз или написать напрямую.

## Фото и видео

- **Медиатека — `assets/media/`.** Фото и короткие видео без звука из собственной съёмки: Ясно Поле, сентябрь 2026; Чиралы, ноябрь 2025. Здесь же фото Стамбула. Что откуда взято — в `assets/media/СОСТАВ.md`. Эти же файлы пойдут в календарь платформы Мастера.
- **Пересобрать из исходников** (папки «Ясно Поле видео» и «Чиралы» на рабочем столе): `bash tools/build-media.sh`. Скрипт:
  - переводит iPhone HDR в обычный цвет;
  - поправляет цвет камеры Sony;
  - режет плавно зацикленные видео по 5–7 секунд;
  - делает фото и картинки для превью ссылок.

  Какой кусок какого ролика взят, видно прямо в скрипте: там же можно поменять кадр.
- **Коллаж «Как это было»** стоит на странице встречи под «Описанием». Сам коллаж описан в `_data/media.yml`. В файле встречи достаточно строки `collage: yasno-pole-2026`: появятся 3 видео и 4 фото. Видео подгружаются и играют, только когда коллаж виден на экране. Если у человека в телефоне включено «уменьшить движение», вместо видео остаются неподвижные кадры.
- **Обложки карточек:**
  - Ясно Поле — кадр из своей съёмки;
  - Чиралы и августовский Стамбул — фото с Wikimedia Commons по свободным лицензиям. Авторы мелко подписаны в подвале (`_data/site.yml` → `photo_credits`);
  - январский Стамбул — вид на море с балкона Elite Hotel Darıca, официальное фото отеля.
- **Фото отеля в Стамбуле** (галерея январского интенсива) официальные снимки Elite Hotel Darıca, с согласия отеля; подпись тоже в подвале. Подробности — в `assets/media/СОСТАВ.md`.
- **Поля в файле встречи:**
  - `photo` — большое фото, 1600 px;
  - `photo_small` — 800 px;
  - `photo_pos` — какая точка фото остаётся в кадре;
  - `og_image` — картинка превью ссылки, JPG 1200×630.

## Публикация

Адрес сайта: **https://evolution.retreatmaster.online/**
(репозиторий `timurumarov1984-afk/evolution-retreats-2027`, ветка `main`). GitHub собирает сайт сам, через 1–2 минуты после изменения. Прежний адрес `timurumarov1984-afk.github.io/evolution-retreats-2027/` сам переводит на новый.

Пока это черновик:
- `draft: true` — поисковики сайт не видят, сверху пометка «Черновик для согласования»;
- `form.endpoint` пустой — заявки не отправляются, вместо отправки человек видит контакты Натальи.

Как устроен адрес `evolution.retreatmaster.online` (так же, как у сайтов других ретритов на retreatmaster.online):
1. У регистратора домена (GoDaddy) есть CNAME-запись `evolution` → `timurumarov1984-afk.github.io`.
2. В корне репозитория лежит файл `CNAME` с этим адресом — по нему GitHub понимает, какой домен обслуживать.
3. В `_config.yml` в `url` стоит этот адрес, а `baseurl` пустой `""`.

Чтобы сменить адрес, поменяйте его во всех трёх местах. Сам сайт `retreatmaster.online` (календарь ретритов) — отдельный, на другом хостинге; его эти настройки не касаются.

## Посмотреть сайт у себя

Нужен Jekyll 3.10, как на GitHub Pages:

```
LANG=en_US.UTF-8 LC_ALL=en_US.UTF-8 jekyll build --baseurl "" && cd _site && python3 -m http.server 8790
```

`LANG` и `LC_ALL` нужны из-за русских букв в названии папки: без них сборка останавливается с ошибкой про кодировку.

## Как устроен

```
_data/site.yml          — общие тексты, контакты, анкета
_events/*.md            — встречи: одна встреча = один файл
_layouts/default.html   — каркас: шапка, подвал, превью ссылки
_layouts/event.html     — страница встречи
_layouts/embed.html     — блок для вставки на другой сайт
_includes/              — карточка встречи, анкета, вопросы, даты и дни недели словами, цена, статус, логотип
index.html, embed.html, calendar.ics
404.html                — страница «Такой страницы нет» со ссылкой на главную
assets/img/favicon-48.png, apple-touch-icon.png — значок сайта для Safari и экрана «Домой» на iPhone
assets/css/site.css     — оформление в стиле Эволюции
assets/js/site.js       — прошедшие встречи, ранние цены, анкета, «поделиться», календарь, высота блока для вставки
apps-script/            — приёмник заявок (Google Apps Script)
assets/media/           — медиатека: фото и видео встреч (СОСТАВ.md — что откуда)
tools/build-media.sh    — нарезка фото и видео из исходной съёмки
_data/media.yml         — коллажи «Как это было»
```
